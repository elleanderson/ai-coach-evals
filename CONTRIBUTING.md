# Contributing

Thank you for helping. Small, careful improvements are the most useful kind.

## How to Make a Change

1. Fork the repository and create a branch.
2. Make your change, with a test where it makes sense.
3. Run the checks described in the README before you open a pull request.
4. Explain the problem you're solving in the pull request, not only the change.

## Style

Writing in this repository follows UK English, with no em dashes or Oxford commas. The [UK Copy Checker](https://github.com/elleanderson/uk-copy-checker) will flag anything that needs another look.

## Behaviour

Be kind, assume good intent and keep feedback about the work. Anyone who makes the space unwelcoming will be asked to leave it.
